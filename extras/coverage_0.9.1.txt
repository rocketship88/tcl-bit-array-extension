What BA_TEST adds (all in bitarray.c, inside #ifdef BA_TEST or #if defined(BA_TEST)): the test command bitarray_test (BitarrayTestCmd) and what it needs.
    bitarray_test maxbits N          the size limit in bits (normal build: 2^40), so the limit can be reached with tiny arrays
    bitarray_test failalloc K ?T?    the allocation after K more successful ones returns NULL, T times in a row; BA_ALLOC / BA_REALLOC
                                     (= Tcl_AttemptAlloc / Tcl_AttemptRealloc in a normal build) are the only allocations that may fail
    bitarray_test getelem W          call GetElem / PutElem with the width W (an array whose width was changed), to run the BA_IMPOSSIBLE panics
    bitarray_test putelem W
    signal handlers for SIGILL, SIGABRT and SIGSEGV that call __gcov_dump() first (only with -DBA_GCOV, which coverage.sh sets): Tcl_Panic ends the
                                     process with SIGILL (or SIGABRT), and a process that is killed by a signal would otherwise lose its coverage counts
