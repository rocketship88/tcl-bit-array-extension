About this page

    
The steps were written from the sources: bitarray.c (version 0.6.0) and the Tcl 9.1 source tree (GitHub mirror, commit
    e36db33; files tclExecute.c, tclListObj.c, tclListTypes.c, tclCmdIL.c,
    tclArithSeries.c). Function names are stable; line numbers and details can drift in later Tcl versions, so check the source
    before relying on a name. The values drawn are computed by this page's own small model of the operations. They are not captured from
    a running Tcl, and the page does not run Tcl or your build. The simplifications are: refcounts count only the variables shown (the real
    value stack holds extra references for a moment); an array has 16 elements here (real ones are as long as you like); and
    capWords is modelled only where a step grows the array (doubling, at least 4 words).

    
Timings and when to prefer a plain list are in performance_analysis.md; the full command syntax is in README.md.
